# gbp-midia

Imagens dos posts do Google Business Profile da operação do Mayron Giacon.

**Este repositório é público de propósito:** o Google só aceita imagem de post
por link público, e baixa a imagem daqui no momento da publicação. Só entram
aqui artes que vão ser publicadas no Google (ou seja, que ficarão públicas de
qualquer jeito). Nada de dado de cliente, rascunho ou documento interno: isso
fica no repositório privado `gestao-gbp`.

Organização: `<cliente>/<AAAA-MM-DD>-<tema>.jpg`

Regras (conferidas pelo conector antes de publicar):

- horizontal, proporção 4:3 (1440×1080);
- PNG ou JPEG, até 5 MB.
